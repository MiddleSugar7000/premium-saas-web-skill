FAQ

Frequently asked questions

Do I need to know how to code to use Flowpilot?

No. You describe agents in natural language or start from a ready-made template. For developers, an API and webhooks are also available.

Is our data safe?

Yes. Data is encrypted and stored in EU data centers, with SOC 2 Type II and GDPR compliance. We never use your data to train models.

Can an agent send email without my knowledge?

Only if you allow it. By default, outbound actions such as sending an email require approval, and you can configure this per agent.

What other tools does it work with?

Besides Slack, Notion and Gmail, we support Google Calendar, Google Drive, Jira, Linear and HubSpot. We keep expanding the list.

What happens after the trial?

You automatically move to the free Starter plan unless you choose a paid plan. No data is lost.
