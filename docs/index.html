FAQ

Questions

What is premium-saas-web?

An open-source Agent Skill: a folder with a SKILL.md file and three reference files. It teaches AI coding agents to build premium SaaS, AI-product, agency and portfolio websites using 4 design directions, 18 copy-ready CSS/HTML recipes and a GSAP + Lenis motion system, all measured from top-selling ThemeForest templates.

Which AI agents does it work with?

Claude Code, OpenAI Codex, Cursor and Google Antigravity, plus any agent that reads the SKILL.md standard. npx skills add MiddleSugar7000/premium-saas-web-skill installs it for all of them.

How was it tested?

With Claude Opus 5.5. The same four one-line prompts ran in separate claude -p processes in empty folders with no memory, once with the skill and once without. 97.5% of automated checks passed with the skill, 75% without. The pages above are the unedited output.
