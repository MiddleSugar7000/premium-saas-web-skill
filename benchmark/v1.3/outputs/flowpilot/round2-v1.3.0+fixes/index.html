06 / FAQ

Questions, answered.

Will agents send things without my approval?

No. By default every message, email and page edit waits for your approval. You can switch an individual agent to autopilot once you trust it.

What can agents see in Slack, Notion and Gmail?

Only the channels, pages and labels you choose when connecting. You can change or revoke access whenever you like.

Do I need to write prompts?

Not to start. Pick a template and go. If you want something custom, describe the job in plain English and Flowpilot sets up the agent.

Can I see what an agent did?

Yes. Each run shows what the agent read, what it decided and what it produced.

What happens if an agent gets something wrong?

Because you approve before anything goes out, you can edit or reject the draft. Feedback helps the agent follow your rules next time.
