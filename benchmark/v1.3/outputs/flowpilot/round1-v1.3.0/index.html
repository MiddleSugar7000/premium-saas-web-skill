FAQ

Questions, answered.

Something we missed? Ask when you request early access and we'll reply personally.

Which apps does Flowpilot work with?

Slack, Notion and Gmail. Agents can work inside one app or hand tasks between all three.

Will an agent send emails without asking?

Only if you allow it. Sending email and posting publicly can each require approval, and approvals are set per agent.

Do I need to write code or build flowcharts?

No. You describe the job in plain English and Flowpilot sets up the agent. You can read and adjust the steps it produced, but you never have to.

Can agents see everything in our workspace?

No. Each agent gets only the channels, Notion pages and Gmail labels you grant it, and you can remove access whenever you like.

What happens when an agent isn't sure?

It stops and asks. Low-confidence steps land in your approval queue with the context it used, instead of guessing.
